# 紫金 URP 自动评估软件

自动完成紫金（URP 综合教务系统）的学生评教：**自动登录 → 拉取未评课程 → 每题自动选最优 → 自动填写主观评价 → 自动提交**。

> 仅供学习交流与提高效率使用，请在拥有正常评教权限的前提下使用，后果自负。

## 功能特性

- 🔐 自动登录（验证码用 `ddddocr` 自动识别，识别错可手动改）
- 📋 自动识别所有"未评估"课程并逐门处理
- ✅ 每题自动选择**最高分**选项（"非常同意"）
- 🛡️ 自动规避站点防作弊：页面 JS `check()` 用 `max(id)-min(id)==0` 拦截"全部一样"，
  本软件默认把**最后一题选次高分**，稳过该校验，对教师总分影响可忽略
- ✍️ 自动填写主观评价（内置 5 套好评模板逐课轮换，也可自定义，≤100 字）
- ⏱️ 可设置"提交前等待秒数"，应对站点"停留满 3 分钟才能提交"的限制
- 🧩 全程 **GBK** 编解码，彻底解决中文乱码问题
- 🖥️ 图形界面，可打包成单个 `.exe` 双击运行

## 适配的站点接口（来自真实页面源码）

| 步骤 | 接口 | 关键字段 |
|---|---|---|
| 登录 | `POST /loginAction.do` | `zjh` 学号 / `mm` 密码(明文) / `v_yzm` 验证码 |
| 验证码 | `GET /validateCodeAction.do?random=` | ddddocr 识别 |
| 列表 | `GET /jxpgXsAction.do?oper=listWj&yzxh=学号` | `<img name="wjbm#@bpr#@bprm#@wjmc#@pgnrm#@pgnr">` |
| 打开问卷 | `POST /jxpgXsAction.do` | `oper=wjShow` + 上述字段 + `wjbz=null` |
| 提交 | `POST /jxpgXsAction.do?oper=wjpg` | `wjbm/bpr/pgnr` + `xumanyzg=zg` + `wjbz` + 各题`name=值` + `zgpj` |

题目选项 `value="权重_得分"`，`id=1` 为 `_1`（满分）。默认服务器 `http://192.168.16.207`，可在界面修改。

## 使用方式

### 方式一：直接用 Python 运行（推荐开发/调试）

```bash
pip install -r requirements.txt
python urp_auto.py
```

### 方式二：打包成 exe（给没有 Python 环境的电脑用）

双击 `build.bat`，完成后在 `dist\紫金URP自动评估.exe`。

### 操作步骤（界面）

1. 确认/修改**服务器地址**（默认 `http://192.168.16.207`，需在校园网内）
2. 填**学号**、**密码**
3. 点**刷新验证码**（装了 ddddocr 会自动识别并预填，不对可手改）
4. 点**登录**
5. （可选）调整"提交前等待秒数"、主观评价文本
6. 点**开始自动评估**，看日志直到完成

## 重要说明：提交前等待时间

页面要求**停留约 3 分钟**后才允许提交（JS 倒计时）。直接发请求虽能绕过浏览器端 JS，
但**服务端是否也校验时间未知**。因此：

- 默认 `等待秒数 = 5`（快速，几十秒评完全部课程）
- 若提交时报"未到提交时间/时间不足"之类错误，说明服务端也校验时间，
  把等待秒数**改回 185**（每门等约 3 分钟）即可。

## 自测（离线，无需联网）

仓库内附带真实页面样本，可离线验证解析逻辑：

```bash
python urp_auto.py --selftest
```

会打印解析到的题目、所选答案、防作弊校验是否通过、课程列表等。

## 常见问题

- **验证码总是错**：ddddocr 并非 100% 准确，多点几次"刷新验证码"或手动输入即可。
- **登录失败**：检查是否在校园网内、服务器地址是否正确、学号密码是否正确。
- **未安装 ddddocr**：仍可使用，验证码改为手动输入（界面显示验证码小图）。
- **打包 exe 很大**：因含 onnxruntime 识别模型，属正常（约 200MB+）。

## 依赖

- `requests`（必需）
- `ddddocr`（可选，验证码自动识别；本机 Python 3.14 已确认可装 onnxruntime 1.26）
- `Pillow`（可选，界面显示验证码图）
