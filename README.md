# 紫金 URP 自动评估软件

自动完成紫金（URP 综合教务系统）的学生评教：**自动登录 → 拉取未评课程 → 每题自动选最优 → 自动填写主观评价 → 自动提交**。

> 仅供学习交流与提高效率使用，请在拥有正常评教权限的前提下使用，后果自负。

## 功能特性

- 🔐 自动登录（验证码用 `ddddocr` 自动识别，识别错可手动改）
- 📋 自动识别所有"未评估"课程并逐门处理
- ✅ 每题自动选择**最高分**选项（"非常同意"）
- 🛡️ 自动规避站点防作弊：页面 JS `check()` 用 `max(id)-min(id)==0` 拦截"全部一样"，
  本软件默认把**最后一题选次高分**，稳过该校验，对教师总分影响可忽略
- ✍️ 自动填写主观评价（内置 5 套好评模板逐课轮换，也可自定义，≤100 字）
- ⏱️ 可设置"提交前等待秒数"，应对站点"停留满 3 分钟才能提交"的限制
- 🌐 支持校外使用：内置深信服 VPN 网页模式，登录网关后自动定位教务系统映射地址
- 🧩 全程 **GBK** 编解码，彻底解决中文乱码问题
- 🖥️ 图形界面，可打包成单个 `.exe` 双击运行

## 适配的站点接口（来自真实页面源码）

| 步骤 | 接口 | 关键字段 |
|---|---|---|
| 登录 | `POST /loginAction.do` | `zjh` 学号 / `mm` 密码(明文) / `v_yzm` 验证码 |
| 验证码 | `GET /validateCodeAction.do?random=` | ddddocr 识别 |
| 列表 | `GET /jxpgXsAction.do?oper=listWj&yzxh=学号` | `<img name="wjbm#@bpr#@bprm#@wjmc#@pgnrm#@pgnr">` |
| 打开问卷 | `POST /jxpgXsAction.do` | `oper=wjShow` + 上述字段 + `wjbz=null` |
| 提交 | `POST /jxpgXsAction.do?oper=wjpg` | `wjbm/bpr/pgnr` + `xumanyzg=zg` + `wjbz` + 各题`name=值` + `zgpj` |

题目选项 `value="权重_得分"`，`id=1` 为 `_1`（满分）。默认服务器 `http://192.168.16.207`，可在界面修改。

## 使用方式

### 方式一：直接用 Python 运行（推荐开发/调试）

```bash
pip install -r requirements.txt
python urp_auto.py
```

### 方式二：打包成 exe（给没有 Python 环境的电脑用）

双击 `build.bat`，完成后在 `dist\紫金URP自动评估.exe`。

### 操作步骤（界面）

1. 确认/修改**服务器地址**（默认 `http://192.168.16.207`，校园网直连；校外见下方『校外访问（VPN）』）
2. 填**学号**、**密码**
3. 点**刷新验证码**（装了 ddddocr 会自动识别并预填，不对可手改）
4. 点**登录**
5. （可选）调整"提交前等待秒数"、主观评价文本
6. 点**开始自动评估**，看日志直到完成

## 校外访问（VPN）

默认只连内网 `http://192.168.16.207`，校外需要先接入学校 VPN。两种方式任选：

### 方式一：EasyConnect 客户端

学校 VPN 门户 `https://223.112.21.198:6443` 提供 EasyConnect 客户端（Windows 直链
`https://223.112.21.198:6443/vpn/user/download/client/windowsclient.zip?ostype=windows`）。
登录后客户端会下发校园网路由，`192.168.16.207` 变成可直连地址，工具保持默认设置即可。

### 方式二：VPN 网页模式（工具内置，免客户端）

1. 「访问方式」选 **VPN 网页模式**
2. 填 `VPN 网关`（默认 `https://223.112.21.198:6443`）、`VPN 账号`、`VPN 密码`
3. 点 **连接 VPN**：工具登录网关 → 读取已授权资源 → 自动找到名称含「教务」的资源，
   把服务器地址切换为 `https://223.112.21.198:6443/<mapid>/`
4. 之后照常：刷新验证码 → 登录 → 开始自动评估

说明：

- VPN 账号密码只用于登录网关，**不保存**，仅存在内存中
- 网关使用自签证书，工具已关闭证书校验
- 未连接 VPN 时点「刷新验证码」会提示先连接
- 支持可选 HTTP / SOCKS5 代理（如 EasyConnect 只开本地端口），格式 `http://127.0.0.1:7890`、`socks5h://127.0.0.1:7891`

深信服网关接口（复刻自网关的 `jquery.sslvpn.js`）：

| 步骤 | 接口 | 关键字段 |
|---|---|---|
| VPN 登录 | `POST /vpn/user/auth/password` | `username/password/encode=0` |
| 资源列表 | `GET /vpn/user/portal/intergration.xml?version=1.0` | `WEB_RESOURCE@mapid`、`@uri`(base64) |
| 资源地址 | `https://网关/<mapid>/` | 其余请求都在该前缀下 |

## 重要说明：提交前等待时间

页面要求**停留约 3 分钟**后才允许提交（JS 倒计时）。直接发请求虽能绕过浏览器端 JS，
但**服务端是否也校验时间未知**。因此：

- 默认 `等待秒数 = 5`（快速，几十秒评完全部课程）
- 若提交时报"未到提交时间/时间不足"之类错误，说明服务端也校验时间，
  把等待秒数**改回 185**（每门等约 3 分钟）即可。

## 自测（离线，无需联网）

仓库内附带真实页面样本，可离线验证解析逻辑：

```bash
python urp_auto.py --selftest
```

会打印解析到的题目、所选答案、防作弊校验是否通过、课程列表等。

## 常见问题

- **验证码总是错**：ddddocr 并非 100% 准确，多点几次"刷新验证码"或手动输入即可。
- **登录失败**：检查是否在校园网内（或已连 VPN）、服务器地址是否正确、学号密码是否正确。
- **VPN 登录提示"用户名或密码错误"**：VPN 账号密码与教务系统账号**可能不同**，以 VPN 门户能登录的为准。
- **VPN 提示找不到教务系统资源**：说明该 VPN 账号没有被授权「教务系统」，需联系网络信息中心开通。
- **VPN 已连接但刷新验证码失败**：多为网关会话过期，重新点「连接 VPN」即可；若资源指向的不是 URP，可手动把服务器地址改成浏览器里看到的 `https://223.112.21.198:6443/<mapid>/`。
- **未安装 ddddocr**：仍可使用，验证码改为手动输入（界面显示验证码小图）。
- **打包 exe 很大**：因含 onnxruntime 识别模型，属正常（约 200MB+）。
